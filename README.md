# P.A.I.R.S

Pairs is the team project for the CS109 Introduction to Computer Programming of 2026. The project implements a simple link and cancel game, where players can link pairs of items and cancel them to score points. The project is implemented in Java and uses libsdl4j for graphics and input handling.

## Build and Test Instructions

The project uses Gradle as the build system. To build the project, run the following command in the project root directory:

```
./gradlew build
```

In development, you can use the following command to run and test the project:

```
./gradlew run  # Runs the main application
./gradlew test # Runs the unit tests
```

On windows, use `gradlew.bat` instead of `./gradlew`.
